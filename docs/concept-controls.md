# 创意池筛选、排序与操作

创意池可组合产品、名称、状态（草稿、入选、淘汰、就绪）与人工评分筛选。评分区间为低于 6、6 至不足 8、8 至 10；另有已评分和未评分。时间按创建时间正序或倒序，评分按高低排序，未评分始终在评分排序末尾，相同排序值用对象 ID 稳定排序。

`GET /api/v1/concepts` 增加 `sort=time-desc|time-asc|score-desc|score-asc` 和 `rating=all|scored|unscored|high|medium|low`。排序和筛选在服务端、分页前执行，保持团队和 API Key 产品范围约束。

卡片评分按钮打开 0–10 分编辑窗口，留空清除评分。更新携带基础版本并保存不可变修订，冲突返回 409。卡片删除按钮确认后将状态修订为 archived；在已归档中可恢复为草稿。没有物理删除、级联删除、删除文件或清空策划案引用。只读用户可查看评分，不能调整或删除。

本地验收创建 33 条隔离测试创意，验证跨页排序、未评分、状态、评分版本冲突、删除恢复、关联策划案保留与 390px 手机布局。线上仅验证已有数据的只读筛选排序，不修改真实创意。
