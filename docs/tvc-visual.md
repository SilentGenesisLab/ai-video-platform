# TVC 制作工作室视觉升级

首页、登录页和工作台统一定位为 TVC 制作：产品需求、Brief、创意策划、工业分镜、视觉资产、视频片段及成片交付。首页使用虚构的 MORNING 随行杯示例，不读取团队资料；分镜与时间线为演示，不宣称自动剪辑或实际投放效果。

保留森林绿与荧光绿，增加鼠尾草绿、暖白及柔和渐变。磨玻璃用于导航、悬浮信息、弹窗和助手面板；业务卡片采用高不透明度表面，保证正文与表格清晰。样式集中在 `src/app/visual.css`，同时覆盖深浅色工作台、团队页与管理后台；减少动态效果设置下关闭动效。

验证范围：390、768、1440 像素官网、登录和注册布局及密码眼睛按钮；七个制作模块、分镜所属策划、产品详情、下拉菜单、个人设置、助手和团队页的深色表面与浅色恢复。发布仅替换 Web 镜像，不调整模型采购价、不发起付费生成、不改变制作数据。

部署沿用现有 HTTPS 与 1.4 管理后台数据库。构建使用当前生产依赖镜像并合并仓库最新代码，回退采用切换前的 Web 镜像。本次没有新增数据库迁移。
