# 1.4.2：AI 引用编辑与生成结果卡片

各业务资源卡片的 AI 协作按钮传入明确对象。产品详情和创意/策划案/分镜/资产/脚本编辑器采用同一入口；编辑器先保存当前修改再加入引用。引用支持移除、会话草稿保存和刷新恢复。

发送 referenceIds 时校验团队、产品范围和会话产品，持久保存原对象版本/内容。Agent 将引用作为用户上下文，读取最新对象后使用 baseVersion 修改原对象；已有 409 保护保留。

新增 /tools/generate-media：仅需类型、产品和提示词，自动选用已启用媒体渠道、记录报价并提交。图片直接排队扣积分，不再询问渠道/价格；视频保留人工审批和原报价快照约束。请求幂等保护沿用统一 API。

/conversations/{id}/media 返回当前运行及历史运行的生成批次/任务/签名文件地址。聊天显示占位、待审批、失败原因和完成后的图片/视频；刷新恢复，轮询不重购，签名更新不会持续打断播放。

验证：42 个单元测试、10 个 Python 流式/引用测试；事务回滚集成检查引用版本、跨产品拒绝、自动报价、图片立即排队、视频不排队及会话恢复，不调用付费媒体。Playwright 验证引用添加/移除/刷新/请求参数，以及占位转图片结果；真实 DeepSeek 修改指定创意为新版本，保留其余字段且不新建副本。

迁移只新增 Message.contextRefs JSONB 默认 []，兼容旧消息。
