# 会话视频积分确认（1.5.1）

视频生成仍先创建 pending_approval 批次，该状态在会话显示为“等待积分确认”。打开创作搭档时，对有权限的待确认视频自动弹出窗口，显示生成数量、总积分、付款钱包、可用积分和生成内容。图片继续直接生成。

“同意生成”提交绑定最新快照 digest 的人类确认，事务内创建任务并冻结发起人的个人积分；Worker 后续调用供应商，结果转存后在会话显示可播放视频。“取消生成”拒绝批次，不产生生成任务或扣费；关闭弹窗为稍后决定，可从卡片重新打开。余额不足不能确认；服务端也校验余额。取消/失败继续沿用原结算退款及提交结果待确认规则。

人类发起人具有 write+generate 时可确认自己的批次，不需要团队审核角色。其他有 approve 权限的人类仍可审批。Agent、只读用户和没有审批权限的其他成员不能确认；产品和团队访问范围仍受校验。

弹窗先 POST /production-batches/{id}/refresh-quote，生成新的报价记录及审批摘要，保留原报价；不冻结、不创建 Job、不调用供应商。旧摘要、过期报价或价格变化拒绝生成，展示新报价后需要再次点击同意。重复确认只创建一次任务。会话媒体查询返回报价信息、确认权限、提示词概览及任务结果，屏蔽渠道凭据。

验收：5 项 Playwright 覆盖同意后占位/结果、取消、余额不足、稍后决定及过期摘要重新确认；页面媒体与供应商结果模拟，不触发真实付费生成。数据库集成使用回滚事务，验证人类编辑可确认本人 Agent 视频、确认前冻结余额不变、确认后精确冻结报价、Agent/旧摘要/重复确认拒绝，所有任务与报价均回滚。
