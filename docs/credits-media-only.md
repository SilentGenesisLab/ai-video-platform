# 1.4.1：交互与积分规则

- Enter 发送；Shift+Enter 换行。中文输入法组合期间 Enter 不发送，执行中不会重复提交。
- 手机注册、后台创建账号和首次初始化管理员各赠送 20000 个人积分。额外创建或加入团队不再次赠送，现有账户余额不自动改写。
- 只有 image/video 生成冻结和消耗积分；文本、识图、附件/视频理解、搜索、音频/音乐不扣个人积分。供应商成本仍正常统计。
- 每次新报价保存 media-only-v1 策略；历史冻结和流水沿用原策略，未知提交仍禁止自动重购。视频审批要求保留。
- 修复线上两次创作搭档因个人余额不足暂停：免费请求不再要求正余额，旧会话可点继续。

验证包含：TypeScript 与生产构建、42 个单元测试、团队 HTTP 37 项、模拟供应商流式与幂等、个人钱包守恒/并发/零余额/历史兼容；Playwright 检查创建赠送、Enter 真实流、Shift+Enter 和输入法。
