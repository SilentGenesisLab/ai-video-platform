# 会话标题与批量创意评分

首次用户请求由 DeepSeek 生成简短标题，经持久化 title 事件更新会话列表；附件独立发送也支持。标题调用不展示为聊天正文，不消耗个人积分，失败不阻断正文。刷新读取已保存标题，后续消息不重命名。

创意页“一键评分未评分创意”对当前产品（未选则当前团队全部产品）的全部未评分创意提交后台任务，跨分页处理，不受列表搜索限制。五维权重：产品/用户25%、钩子25%、原创性20%、叙述逻辑15%、制作可行性15%。服务器验证维度和分数并计算0–10加权总分。每条保存理由、模型、时间、来源版本和不可变修订。评分是策划质量参考，不代表预测转化率。

人工0分也是已评分，保留所有已有评分。提交后被修改的内容跳过，不覆盖人工改稿。任务进度和逐条失败保存在日志中，成功条目不会因其他失败回滚。失败的未评分创意可再次提交。一支团队同一时间仅一个评分任务，防止重复消费供应商请求。文本评分免费，不生成媒体。

接口 POST /api/v1/concepts/score-unscored，参数可选 productId，要求人类登录、write 和 generate；GET /api/v1/jobs/{id} 查看进度。公共接口契约提供详细字段。
