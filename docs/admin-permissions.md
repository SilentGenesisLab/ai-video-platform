# 管理权限与后台入口

平台身份分管理员与普通用户，独立于团队角色。现有 `platformAdmin` 作为权限事实来源，不扩大团队管理员权限。管理员打开左下角账号菜单后可进入管理后台；普通用户不显示入口，访问 `/admin` 返回工作台，所有后台 API 继续由服务端校验人类登录及平台管理员身份。

后台包括仪表盘、经营分析、AI 能力管理、用户管理，另保留积分管理。用户详情可编辑姓名与管理员身份、增减个人积分并填写原因、查看积分流水；停用与降权使已有会话失效，不能移除最后一个有效管理员。

仪表盘 `/api/v1/platform/overview` 按 Asia/Shanghai 自然日显示注册、模型调用的独立操作者、调用任务与已结算积分，连续补齐十四天的数据。调用包含文本、识图与媒体；免费调用消耗为零，冻结金额不算已消耗。失败表仅返回最近十条调用的必要字段，错误信息脱敏。经营分析保留时间、团队、用户、渠道及模型筛选、费用依据与模型消耗汇总。不存在在线充值或收入数据，不虚构经营收入。

验收覆盖管理员菜单入口、五个栏目、十四日统计、手机布局，普通用户页面与接口拒绝、积分调整拒绝，以及本地用户积分增减、停用与会话撤销、渠道配置及分配。生产验收只读，不对真实用户调整积分，不触发模型生成。
