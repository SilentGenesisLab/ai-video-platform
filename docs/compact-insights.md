# 紧凑洞察与统一选择组件

产品洞察使用桌面双栏、手机单栏；已有条目默认只显示描述，每个分区同时展开一条。新增条目自动展开，证据与其他字段仍随版本完整保存。素材备注和文件编辑收起，上传记录完成后收起。创意卡片删除文字封面，名称只出现一次，展示洞察摘要、更新时间、0–10 评分。

共享 Select 组件用于产品、策划、制作、渠道、团队和助手的单选/多选。搜索、键盘、空值、禁用、弹层与表单提交共用一套行为；关联文件多选保留原有 ID。产品 API 及版本冲突约定不变。

新增平台管理员接口 `POST /api/v1/platform/rates/official-deepseek`，仅为官方直连 deepseek-flash 补齐缺失 text/vision 价格，保留所有已有配置。核验来源：https://api-docs.deepseek.com/zh-cn/quick_start/pricing/ （2026-10-12）。按官方高峰人民币上限配置：输入 2、缓存 0.04、输出 8 元/百万 Token；空闲官方价为一半。界面和价格依据明确标注上限计算，不能当作供应商实际账单。该操作不触发模型调用。

解析失败的素材和任务提供采购价入口，链接直接进入 `/team?tab=platform#purchase-rates`。AI Centre ASR 文档不提供采购价，渠道也未配置转写型号，因此继续显示待配置，不虚构价格。补价不自动重新购买解析，保留原失败记录，由用户主动重试。

验证：生产构建、TypeScript、34 项单元测试、17 项产品洞察 API 检查通过。浏览器覆盖紧凑默认态、展开保存与刷新、双栏/手机、单选键盘、多文件关联、创意卡片及官方价格初始化与重复调用；没有调用付费媒体生成。发布前备份生产数据库，以独立目录构建，保留旧镜像及配置，切换前校验当前镜像没有被其他发布更改。
